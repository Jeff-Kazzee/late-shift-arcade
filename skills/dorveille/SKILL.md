# Dorveille — optional reflection

Dorveille is a bounded thinking aid, not a project operating system.

Use it only when Jeff explicitly invokes it. It never:

- installs hooks or injects prompts after compaction;
- creates state chips, ledgers, hypnograms, or calibration files;
- spawns agents or creates worktrees;
- owns project truth, tasks, memory, branches, or completion;
- changes scope or edits its own rules.

Read `STATE.md` and the one relevant Vivary artifact first. Then produce:

1. the original question in one sentence;
2. the strongest verified evidence;
3. the load-bearing assumption;
4. one credible alternative;
5. the smallest test that would distinguish them.

Stop after that pass. Decisions go in `decisions/`, work goes in `changes/`,
verification goes in `verification/`, and assignments/receipts go through
Agent Relay.
