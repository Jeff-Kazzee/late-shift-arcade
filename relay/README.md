# Late Shift Arcade Relay

Relay owns assignments and receipts only.

- `tasks/` — ready, claimed, working, review, or parked work records.
- `receipts/` — evidence left by an actor at a status transition.
- `done/` — completed task records.

Product truth lives in Vivary artifacts and `STATE.md`. Code truth lives in Git.
Do not copy a roadmap or GDD into a Relay task.
